# Enterprise Automation Project Overview

This repository provides a high-level overview of process automation work completed using UiPath in a semiconductor manufacturing environment.

## Project Summary

Designed and implemented automation workflows to reduce repetitive manual operational tasks and improve process efficiency.

## Impact

- Reduced manual workload by more than 165 hours per week
- Improved process consistency and operational efficiency
- Supported manufacturing operations through automation initiatives

## Technologies

- UiPath
- Process Automation
- Workflow Design
- Operational Process Analysis
